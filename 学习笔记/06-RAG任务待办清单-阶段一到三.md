## 1. 阶段一：题目准入、批量建索引和运行保障 ★ 我现在的战场

**目标**：让现有题库安全、稳定地进入"可检索"状态。

### 1.1 设计决策（做之前必须先定，别自己拍板）

- [ ] 确认索引表方案：**新建 `problem_retrieval_index`** 还是**扩展 `ai_retrieval_chunks`**
      （冲突点：现有表的 `user_id` 是 `NOT NULL`、唯一键是 `(owner_type, owner_id, text_hash)`，
      而题库索引是**全局共享**的，不属于任何用户）
- [ ] 把上面这个设计问题**发给老师确认**（这是阶段一的第一件事，不是最后一件）
- [ ] 定下索引状态字段：`problem_id`、`content_hash`、`index_status`(PENDING/READY/FAILED/BLOCKED)、`index_version`、`embedding_model`、`embedding_dimension`、`indexed_at`、`last_error`

### 1.2 题目检索文本构建（最容易、最该先做、最需要老师确认）

- [ ] 写一个**纯函数**：输入 `ProblemEntity`，输出一段检索文本
- [ ] 文本包含：标题 / 题面摘要 / 输入输出特征 / 知识点 / 算法标签 / 数据范围和复杂度要求 / 难度 / 适用课程
- [ ] 文本**不包含**：标准解、隐藏测试、源码、判题日志、未审核草稿
- [ ] 补单元测试，至少覆盖 4 种情况：正常题、无标签题、超长题面、空题面

### 1.3 准入规则

- [ ] 只索引：公开 + 已审核 + 未归档 + 当前用户可访问
- [ ] 排除：草稿题、私有题、删除题、违规题
- [ ] 题目修改后，按 `content_hash` 判断是否需要重新索引
- [ ] 归档 / 删除 / 恢复题目时，同步更新索引状态

### 1.4 批量索引任务（阶段一的核心）

流程：读取准入题目 → 生成检索文本 → 算内容哈希 → 调 Embedding → 写索引表 → 记录统计

- [ ] **幂等**：重复执行不产生重复记录
- [ ] **分批处理** + 失败重试
- [ ] **并发上限** + Embedding 容量控制（参考 `AiCapacityService`）
- [ ] **单题失败不影响其他题目**
- [ ] 结束输出：成功数 / 失败数 / 跳过数 / 耗时
- [ ] 支持按题目范围、更新时间或索引状态重跑

### 1.5 增量索引

- [ ] 新建 / 发布题目 → 创建索引
- [ ] 修改题面、标签、难度 → 哈希变化 → 重新索引
- [ ] 归档题目 → 停止召回或标记 `BLOCKED`
- [ ] 恢复题目 → 重新进队列
- [ ] 删除题目 → 删除或废弃索引
- [ ] Embedding 失败 → 保留 `FAILED` + 异步重试
- [ ] ⚠️ **索引更新绝不阻塞题目主业务**：题目发布成功和向量索引成功是两个独立状态

### 1.6 阶段一验收标准（任务书第 197~201 行，逐条自己测）

- [ ] 现有符合准入条件的题目都能批量进索引
- [ ] 重复执行不产生重复向量记录（**幂等**）
- [ ] 修改题面后，旧索引不再作为最新结果返回
- [ ] 私有、归档、删除的题目不会出现在学生结果里（**权限隔离**）
- [ ] Embedding 服务异常时，题库基本功能仍然可用（**降级**）

> 🎓 第 2、3、4、5 条是**工程质量**考点，不是功能考点。
> 新手最容易只做第 1 条然后说"做完了"。建议：**每一条写一个对应的测试方法**。

## 2. 阶段二：通用语义检索服务和学生端入口

**目标**：让学生能用自然语言找题，同时形成后续能力共用的后端检索层。
（阶段一验收通过后再开始）

- [ ] 实现题库语义检索服务
- [ ] 支持三种模式：`KEYWORD` / `SEMANTIC` / `HYBRID`
- [ ] 支持过滤：难度、算法、知识点、课程
- [ ] **服务端**权限和题目状态过滤（在返回结果前完成）
- [ ] 接口：`GET /api/v1/problems/semantic-search`
- [ ] 返回：题目摘要 + 匹配分数 + 匹配原因 + 深链 + 是否降级
- [ ] Embedding 不可用时降级到关键词 + 结构化过滤
- [ ] 学生端 Problems 页面接入自然语言搜索
- [ ] 不向前端暴露内部向量分数细节

**API 必须设计成通用能力**，后续被这些模块复用：学生搜题 / 教师组卷 / 相似题检测 / AI 出题 RAG / Tutor 推荐。
